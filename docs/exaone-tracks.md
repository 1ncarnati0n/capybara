# EXAONE 두 트랙 운용 가이드 (en2ko)

## 한 줄 요약

> RTX 4080 SUPER 16GB + EXAONE 패밀리 조합에서 **"더 빠른 속도 + 더 나은 품질"을 동시에 만족하는 단일 모델은 없다.** 두 목표는 트레이드오프이므로 책 성격에 맞춰 둘 중 하나를 고른다.

## 왜 단일 해법이 없는가

- **EXAONE 4.0** (2025-07): 1.2B / 32B만 출시 — 7.8B 사이즈 자체가 없음
- **EXAONE 4.5** (2026-04-09): 33B VLM만 출시 — 가장 작은 GGUF인 IQ4_XS도 18GB → 16GB 단독 적재 불가, IQ3 quants 미공개
- **EXAONE Deep**: 추론 모델 — 번역 task에 추론 토큰은 노이즈, 속도↓·비용↑
- 결론: 7.8B 클래스에서 **EXAONE 3.5 7.8B Q6_K**는 사실상 sweet spot. 이를 개선하려면 (a) 사이즈를 32B로 올려 품질↑·속도↓로 가거나, (b) speculative decoding으로 같은 7.8B의 품질을 유지한 채 속도↑로 가는 것 외엔 의미 있는 선택지가 없다.

## 트랙 비교

| 항목 | 현행 (default) | 속도 트랙 | 품질 트랙 |
|---|---|---|---|
| 구성 | EXAONE 3.5 7.8B Q6_K | 7.8B Q6_K + 2.4B Q4_K_M draft | EXAONE 4.0.1 32B IQ3_M |
| 베이스 사이즈 | 7.8B | 7.8B (target) + 2.4B (draft) | 32B |
| 모델 디스크 | 6.4GB | 6.4 + 1.5 = 7.9GB | 14.4GB |
| VRAM 사용 (KV 포함) | ~10GB | ~10–11GB | ~15.5GB (빠듯) |
| 품질 | 기준 | **기준과 동일** (rejection sampling) | ↑↑ (14T 토큰 학습) |
| 토큰/초 (상대) | 1.0× | 1.5–2× | 0.25–0.3× |
| 책 한 권 예상 | 1× | **0.5–0.7×** | 3–4× |
| llama.cpp 요구 | 일반 | `--model-draft` 지원 빌드 | b5932 이상 |
| 상세 가이드 | (현행) | [track-speed-speculative.md](./track-speed-speculative.md) | [track-quality-exaone4.md](./track-quality-exaone4.md) |

## 어느 트랙을 언제 쓸까

| 상황 | 권장 |
|---|---|
| 일반 소설·에세이, 빠르게 끝내고 싶을 때 | **속도 트랙** (품질은 현행과 동일) |
| 짧은 기술서·매뉴얼·논문체, 정확도가 중요할 때 | **품질 트랙** |
| 서버 한 대만 띄우고 싶을 때 | **속도 트랙** (VRAM 여유) |
| 일관성 검증용 reference 번역이 필요할 때 | **품질 트랙**으로 한 챕터 → 속도 트랙으로 나머지 비교 |
| 16GB GPU 하나에서 듀얼 LLM 동시 가동 | **둘 다 불가** — 한 번에 한 트랙만 |
| `cache/llm` 재사용으로 빠르게 재돌리고 싶을 때 | 두 트랙 모두 OK (캐시는 모델별로 자동 분리) |

## 왜 7.8B Q6_K가 여전히 default인가

- 5–10분짜리 단편 EPUB부터 한 권짜리 장편까지 가장 자주 쓰이는 케이스에서 속도/품질/안정성이 모두 무난
- 32B의 IQ3는 양자화 손실이 누적되어 긴 문맥에서 일관성이 흔들릴 수 있음
- speculative는 draft 모델을 추가로 받아야 하므로 첫 도입 비용이 있음
- 새 트랙은 "필요할 때 옵션으로 켠다"가 자연스러움

## 의도적으로 제외한 옵션

- **EXAONE 4.5 33B**: IQ4_XS 18GB → 단독 적재 불가. 추후 IQ3 quants가 공개되면 재검토.
- **EXAONE Deep 7.8B/32B**: 추론 토큰이 번역 출력에 섞이거나 길이가 늘어 비효율.
- **EXAONE 3.5 32B Q4_K_M (~19GB)**: RTX 4080 SUPER 단독 부적합. 현 `app.py` 프리셋에 남아 있다면 제거 권장.
- **EXAONE 3.5 7.8B Q8_0 / IQ4_XS 교체**: Q6_K 대비 체감 차이 미미.
- **EXAONE 4.0 1.2B**: 7.8B 대체 불가능 — 번역 품질 부족.
